# API Endpoints — N/A

> **Status**: Not applicable
> **Last reviewed**: 2026-11-06

FlowForge does **not** expose an HTTP API. Its public interfaces are:

- the `flowforge` CLI (installer, update, onboard, doctor, init);
- the IDE packs (agents, commands, skills) generated for OpenCode, Cursor, VS Code,
  Antigravity, Copilot and Kilo;
- the Engram MCP/CLI surface, which is documented by `engram-dotnet`, not by this repo.

If a first-party HTTP API is introduced, replace this file with a real endpoint reference
(method, path, auth, request/response, errors) before publishing the feature.
