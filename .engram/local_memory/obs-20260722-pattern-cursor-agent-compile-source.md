## What

Cursor agent files under `ide/cursor/agents/forge-*.md` are **compiled artifacts** generated by `compile-agents-from-skills.py` from `skills/forge-*/SKILL.md`. They must NOT be edited directly.

## Why

This caused a false-resolved rework cycle (Cycle 1 of agent-quality-improvement): the fix was applied to `ide/cursor/agents/forge-orchestrator.md` but `git diff` showed zero changes because the real source is `skills/forge-orchestrator/SKILL.md`. The compiled file is overwritten on every `bash ide/install.sh` run.

## Where

- Source: `skills/{agent}/SKILL.md`
- Compiled: `ide/cursor/agents/{agent}.md`
- Compiler: `ide/cursor/compile-agents-from-skills.py`
- Recompile: `bash ide/install.sh`

## Learned

1. Always edit the SKILL.md source, not the compiled .md file
2. After editing SKILL.md, recompile via `bash ide/install.sh`
3. Verify both source AND compiled output match expected changes
4. This applies to ALL Cursor agents (forge-orchestrator, forge-arch, forge-dev, forge-plan, forge-verify, forge-memory, forge-teacher)
5. VS Code, OpenCode, and Antigravity agents are NOT compiled — they are source files edited directly
