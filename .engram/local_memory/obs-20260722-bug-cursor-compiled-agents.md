## What
Cursor agents in `ide/cursor/agents/*.md` are **compiled artifacts** generated by `python ide/cursor/compile-agents-from-skills.py`. Editing the compiled `.md` file directly is WRONG — the next recompile overwrites the change.

## Why
Rework Cycle 1 (agent quality improvement) applied the fix to `ide/cursor/agents/forge-orchestrator.md` directly. When the fix was verified, it was correct. But the source of truth is `skills/forge-orchestrator/SKILL.md`. The fix needs to go into SKILL.md, then recompile.

## Where
- Source: `skills/{agent}/SKILL.md`
- Compiled: `ide/cursor/agents/{agent}.md`
- Compiler: `ide/cursor/compile-agents-from-skills.py`
- Installer: `bash ide/install.sh` regenerates all Cursor agents

## Learned
- Always identify whether a file is SOURCE or COMPILED before editing
- Cursor agents = compiled. VS Code agents = handwritten. OpenCode agents = handwritten. Antigravity agents = symlinked.
- When in doubt, check if there's a compile script (`compile-agents-from-skills.py`) or template generator
- Rework pattern: fix source → recompile → verify
